# 필름 색 남김 (실험)

기본 인화 룩은 spektrafilm 데이터베이스의 필름·인화지별 중립 인화 필터를 사용합니다. 이 필터는 필름마다 중간 회색이 중립이 되도록 맞춘 값이라, 같은 인화지에서는 필름 간 색 차이가 작아집니다.

"필름 색 남김"은 각 필름의 중립 필터와 고정 기준 필터(같은 인화지에서 Portra 400의 중립 필터)를 섞습니다. 섞는 비율은 조합마다 계산합니다. 기존 LUT는 필름별 중립 보정 100%를 유지합니다.

```
appliedCC = amount × filmCC + (1 − amount) × referenceCC
새 LUT: amount = 조합별 계산값 (0.2 ~ 1)
기존 LUT: amount = 1.0
```

- `amount = 1`이면 기본 룩과 같습니다. 테스트에서 비트 단위로 같은지 확인합니다.
- 필터를 0(필터 없는 확대기) 쪽으로 줄이지 않습니다. 이전 30% 실험은 `appliedCC = 0.3 × databaseCC`였고, 오렌지 마스크 보정까지 줄어 C200 + Crystal Archive의 중간 회색이 [206, 80, 43]의 진한 주황이 됐습니다. 현재는 필름 필터와 기준 필터 사이를 섞습니다. 중립색에 가까운 결과를 보장하지는 않습니다.
- 사진별 자동 보정, 이미지 통계, 출력 RGB 혼합은 쓰지 않습니다. 중간 회색 인화 노출 정규화는 기본 룩과 같이 켜져 있습니다.

## 색 방향 지정 (C200)

필름 데이터대로면 C200은 모든 인화지에서 18% 회색이 주황·노랑(CIELAB 색상각 51~63°)으로 남습니다. 알려진 C200의 초록·청록 느낌과 반대여서, C200만 색 방향을 직접 지정합니다.

```
appliedCC = filmCC + hueShiftCC,  hueShiftCC = [0, M, Y]
```

- 기준 필터와 섞지 않고(`amount = 1`) 필름 자신의 중립 필터에 M·Y 이동량을 더합니다.
- 이동량은 18% 회색이 색상각 180°(초록~청록), 다른 필름과 같은 세기(C* 6)가 되도록 인화지마다 계산합니다(0.1 CC 단위). 결과는 M +4.3~+6.0, Y +2.4~+3.9 CC입니다.
- 카탈로그 `filmCast.targetHue`와 각 변형의 `directionPolicy: editorial-hue`, `targetHue`, `hueShiftCC`에 기록합니다. 화면의 M·Y 슬라이더는 이 이동량에서 시작합니다.
- 다른 15종은 기존 방식 그대로입니다. 색상각 180°는 미리보기 검토로 정한 편집 기준이며 실측값이 아닙니다.

## 비율과 강도

처음에는 모든 조합에 30%를 고정했지만, 같은 30%여도 18% 회색에 남는 색의 세기가 필름마다 CIELAB 채도(C*, D65) 0~39로 크게 달랐습니다. 예를 들어 C200·X-Tra 400은 23~39로 너무 강하고, Gold 200은 5~7로 거의 보이지 않았습니다.

그래서 비율 대신 결과의 세기를 맞춥니다. 18% 회색을 렌더링한 sRGB 값의 C*가 목표값이 되도록 조합마다 `amount`를 계산하고, `amountPolicy: chroma-target`, `amount`, `percent`, `targetChroma`를 카탈로그와 각 LUT의 provenance에 기록합니다. UI는 기존 화면 구성을 그대로 쓰고, 표시하는 퍼센트만 조합별 값을 보여 줍니다.

| 대상 | 목표 C* |
|---|---|
| 기본 | 6 |
| Vision3 200T, 500T | 10 |

`amount`의 하한은 0.2입니다. 하한에서도 목표에 못 미치면 0.2를 씁니다(예: Gold 200). Portra 400은 기준 필름이라 비율과 관계없이 색이 같으며, 0.2로 기록합니다.

퍼센트는 인화 필터 혼합 비율입니다. 미리보기와 다운로드 LUT의 적용 강도는 기존과 새 버전 모두 100%입니다.

## 제공 범위

- 네거티브 필름 16종 × 인화지 8종, 모든 128개 조합에 제공합니다. 마젠타 색상각이나 특정 필름으로 제외하지 않습니다.
- Portra 400도 선택하고 다운로드할 수 있습니다. 다만 필름 필터가 혼합 기준과 같으므로 두 버전의 색은 정확히 같습니다. 화면에도 이를 안내합니다.
- Ektar 100, Portra 160, Gold 200의 일부 인화지처럼 분홍·마젠타 쪽으로 남는 조합도 같은 목표 채도로 생성합니다.
- 인화 단계를 거치지 않는 디지털 스캔, 슬라이드, 제공된 후지 시뮬레이션 LUT에는 이 옵션이 적용되지 않습니다.

`catalog.json`의 `filmCast.skipped`는 빈 배열입니다. 검증 단계에서 네거티브 인화 조합이 하나라도 빠지면 배포를 중단합니다.

## 한계

- C200을 뺀 필름의 색 방향은 보정 필터 데이터베이스가 정합니다. 사람들이 기억하는 필름 색(예: "노란 골드")을 보장하지 않습니다. X-Tra 400(주황), Gold 200·Ultramax 400(분홍) 등도 알려진 색과 방향이 다릅니다.
- 목표 채도는 미리보기 검토로 정한 편집 기준이며, 실측한 현상소 레시피가 아닙니다. 분홍·마젠타 방향의 색도 그대로 제공합니다.
- 세기는 중간 회색에서만 맞춥니다. 밝은 부분과 어두운 부분, 다른 색의 변화량은 필름마다 다를 수 있습니다.
- Vision3 50D·250D처럼 시네마 데이라이트 필름도 스틸 필름 기준 필터와의 차이 때문에 청록 쪽으로 남습니다.

## 생성

```sh
.venv/bin/python -m pipeline.generate_film_cast --jobs 3
.venv/bin/python -m pipeline.generate_film_cast --only kodak_gold_200__fujifilm_crystal_archive_typeii
```

기본 룩 148개의 파일과 번호는 바꾸지 않습니다. 변형은 `public/luts/<기본 ID>__filmcast/`에 생기고 번호는 기본 번호 + 1000입니다. 카메라별 STD·ZIP은 기존 `rebuild_standard`로 만듭니다. 다운로드 파일명은 인화지 코드 뒤에 `FC`를 붙입니다(예: `Gold200CAFC.cube`).

빌드 리포트는 `artifacts/film-cast/build-report.json`에 남습니다.
